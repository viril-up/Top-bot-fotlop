# Viril Training

Отдельный модуль подраздела «Развитие → Тренировки».

- HTML/CSS/JavaScript без сборщика.
- Каталог и программы хранятся отдельно в `data/`.
- Светлая голубая тема.
- XP передаётся в основной профиль через безопасное сообщение iframe.
- Для каждого повтора: начальный уровень — 1 XP, средний — 3 XP, продвинутый — 5 XP.

Откройте `index.html` на GitHub Pages внутри папки `viril_training_module/`.

Примечание: этот первый коммит содержит базовый каталог для проверки интеграции. Большой набор SVG-кадров из архива будет перенесён отдельным этапом; текущие иллюстрации — лёгкие встроенные векторные схемы.
